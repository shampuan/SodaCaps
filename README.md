# SodaCaps
Soda Cap Matching Game


SodaCaps is a free soda cap matching game enriched with sound effects and quality free music by Kevin MacLeod. All content is free and legal (GNU GPLv3). I created the soda caps in the game by applying color effects to a "public domain" image with GIMP. All licensed under Creative Commons.

The game consists of a total of 50 levels (5 levels). It is very enjoyable and immersive to play. It allows you to relieve stress and exercise your brain in your spare time. It is especially suitable for holding competitions for students in schools.

The game was written in the Python programming language and no game engine was used. Sounds are played with the Pygame engine. All game mechanics are driven by python scripts.

The game has minimal dependencies and all dependencies are pulled from the APT repositories of your debian system. Therefore, an internet connection is required to install the game without any problems.
